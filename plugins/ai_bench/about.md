## Getting Started

<!-- https://platform.openai.com/settings/organization/api-keys -->

1. First, install the **AI Bench** plugin for Blockbench
2. Create an API key at [openai](https://platform.openai.com/api-keys)
3. Go to `Settings > Application > OpenAI Key` and paste your API key there.
